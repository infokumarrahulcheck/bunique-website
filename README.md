# Bunique Service & Consultancy — GitHub Ready Website Package

## Folder structure

- `index.html` — main mobile-first single-page homepage
- `css/style.css` — complete visual system, responsive layout and animations
- `js/main.js` — scroll reveal, counters, progress bar, magnetic buttons, tilt effects and interaction logic
- `assets/images/` — homepage visual references and Bunique branding
- `assets/effects/` — transparent PNG overlays used for glow, particles, growth arrows, grid and celebration effects
- `assets/icons/` — service icon placeholders in a consistent glass/blue/gold style
- `docs/` — implementation notes

## Design direction

Deep navy / electric blue / purple / gold gradient theme, mobile-first, long-scroll storytelling, glassmorphism cards, growth visuals and conversion-focused CTAs.

## Important brand asset note

Marketplace/platform logos shown in the generated reference sheets are for visual reference only. Before public launch, replace any third-party logos with their official/current brand assets and review their applicable brand-use requirements.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this package (not the outer folder itself).
3. Ensure `index.html` is at the repository root.
4. Go to Settings → Pages.
5. Select Deploy from branch → main → `/root`.
6. Save and wait for GitHub Pages deployment.
7. Later connect `infobeunique.in` through GoDaddy DNS.
